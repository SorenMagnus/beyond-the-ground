# 浏览器验收

使用 Chrome 和 Playwright 验证实际页面。三个原型的截图和场景状态记录见 [qa/prototypes](../qa/prototypes)。桌面截图审查发现地台过亮、扫描轮廓缺失和部分中文标题换行，已调整材质、轮廓和字号。后续自动化发现手机横向溢出及低速滚动时相机控制权交还不及时，已修改视口裁切和累计滚动判据。

运行 `npm run qa` 生成四种视口、七组转场、研究弹窗、安全图和降级模式的截图及 `qa/final/results.json`。该报告同时记录 GPU、帧时和绘制调用。触摸结果来自浏览器仿真，需在实体设备上另行测量移动性能。

最终复测通过 70 项浏览器检查和 9 项计算与场景测试。复核了 390 × 844 首屏完整标题，以及 1440 × 900 拆解过程中的说明与部件列表。[机器可读结果](../qa/final/results.json)。

桌面抽样使用 Windows、Chrome Headless、Intel UHD Graphics、1440 × 900、DPR 1。768 个帧间隔样本的中位数为 5.0 ms，P95 为 7.8 ms，抽样末帧报告 154 次绘制及 41,794 个三角形。数据仅代表该环境和片段。GitHub Pages 入口返回 HTTP 200，公开页面已复测 WebGL、章节直达、模型探索和工程计算。
