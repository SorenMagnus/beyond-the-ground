# Interaction specification and QA inventory

## Controls
章节菜单/hash：跳转并恢复目标镜头；直达和刷新有效。阅读模式按钮：减少强动效，仍可使用计算器和检查器。
模型：进入探索、旋转、front/side/top预设、wireframe、部件列表、复位、Esc退出。选择部件显示说明与事实/示意标识。桌面模型区域可拖动；手机需先主动开启。
飞行：0–100滑杆与四个阶段按钮，可暂停任意进度；退出手动阶段则回滚动控制。
工程：参数范围和单位旁显，实时更新功率/能耗/可行性/曲线，一键复位。
安全：点击或键盘选择系统节点，开关教学故障，显示可用路径和解释，复位。
商业：滑杆改变载客率/班次能力/价格/成本，显示收益、成本、平衡点和情景图；与工程航程和能耗共享。
引用：编号链接打开原始来源；报告抽屉支持 Esc、焦点归还和键盘关闭。

## Input validation
有限数值、正质量/面积/效率/速度；效率范围(0,1]，客座率[0,1]。无法完成任务时显示不可行，不用负剩余电量冒充航程。零载客显示每客指标无定义。班次由任务+充电周转时间限制。

## QA coverage
所有控件检查初始→变化→复位；鼠标拖拽检查相机变化；四个视口截图及横向溢出检查。转场分别检查0/0.5/1与逆向相同进度状态。快速滚动、hash刷新、旋转中滚动、窗口缩放、reduced motion、WebGL禁用、context loss。
性能记录UA、GPU、视口、DPR、帧时统计、draw calls、三角形；软件渲染不宣称物理设备60FPS。
自动化手机仿真与真实手机区分记录。Screenshots来自实际运行网站。
