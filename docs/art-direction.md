# Art direction · BEYOND THE GROUND

## Brief and creative authority
课程：《飞行汽车技术基础》。面向教师、同学及对 eVTOL 感兴趣的公众。用户已委托艺术指导，确认原创 S4 外形研究模型，确认公开发布。代码位于 E:/beyond-the-ground。

核心句：这是一个让你把飞行器拆开，再沿它的推力走进一座城市，最后亲手判断它能否成立的网站。

## Feeling curve
机库的好奇 → 产品显形的惊叹 → 扫描的理解 → 拆解的专注 → 飞行的释放 → 能源与安全的审慎 → 城市场景的想象 → 商业模型的判断 → 天空终章的开阔。
峰值：推进器圆环成为进入天空的入口，工程流线成为飞行航迹。此前使用安静的结构观察，不以粒子噪声制造高潮。

## Visual system
背景 #080d12；正文 #e9eff4；次级文字 #9aabbc；冰川蓝 #b4dce9；强调青 #79ddce。工程章用冷灰蓝，飞行章增加天空亮度，商业章回归深色工作台。
展示字采用本机 Arial Black/Arial 的大写紧字距；中文采用 Microsoft YaHei/PingFang SC。无需字体 CDN。数字用等宽字体及 tabular-nums。
桌面使用 12 列关系，左右边距 5vw，右侧模型、左侧正文；工程拆解用侧栏与引线；安全图、计算器、竞争表具有各自布局。移动端独立上方模型/下方文字构图。主阅读层每行约 26–38 汉字。

## Hero layer contract
远景为机库雾与顶灯；中景为停机坪和后侧空间；主体为原创航空银模型；近景为地面标线；标题为独立 DOM。灯光和材质塑造体积，不用宣传图替代实时模型。静态后备图来自实际模型渲染。

## Authored restraint
不自动播音，不锁滚轮，不强制吸附。数据章给阅读和操作留出停顿。模型探索是明确进入和退出的工具状态。无自定义光标替代系统指针；仅用局部拖拽提示。所有引用可访问，所有教学假设可辨认。
